# Klausurtrainer Religionskritik (Ethik 12)

Interaktive Lern-App für die Klausur zu Theodizee, Religionskritik, Feuerbach und Marx – auf aktives Lernen ausgelegt (erst abrufen, dann vergleichen).

- **Online (mit KI-Korrektur und Sync über Geräte):** https://claude.ai/artifact/VFUptadt7yGtQCSrJNbE5U
- **Offline:** `index.html` im Browser öffnen – alle Übungen funktionieren, Fortschritt wird im Browser gespeichert, KI-Funktionen sind ausgeblendet.

Lernmodi: Brain-Dump, Abfrage (Leitner-Karteikasten), Zuordnen, Lückentext, Zeitstrahl, Vergleichstabelle Feuerbach–Marx, Textarbeit mit Zeilenbelegen, Stellung nehmen, Prüfungsgespräch, Probeklausur.
